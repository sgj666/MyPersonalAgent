# 教案生成（outline → draft）

把结构化入参和依据材料压成一节可执行的课。分两段：先大纲，教师确认后再全文。**不要一次给全文。**

## 1 入参

```json
{
  "mode": "outline",
  "stage": "小学", "subject": "英语", "book": "人教PEP 六年级上",
  "unit": "Unit 3 My weekend plan", "lesson_type": "新授", "hours": "第 1 课时 / 共 6 课时",
  "material_paths": ["knowledge/教材/人教PEP六上-U3.md", "knowledge/课标/英语课标-二级.md",
                     "knowledge/教案/小学-英语-Unit 2-新授.md", "knowledge/作业反馈/六2-U2.md"],
  "class_name": "六(2)班",
  "outline": []
}
```

- `mode`：`outline` 只出大纲；`draft` 写全文，此时 `outline` 带教师改过的 7 行。
- 必需：`stage subject book unit lesson_type hours`。缺哪个一次问完，不要逐条追问。
- `material_paths`：教材原文、课标、同单元旧教案、上次作业反馈。**逐个 `read`**；读不到的记下来，回报时列出「未读到」，不要假装读过。
- 数组为空：按学科常识写，引用来源写「无依据材料，教材外补充」。
- 有同单元旧教案：沿用其中仍成立的部分，只改课型和学情相关段落。

## 2 第一段：outline

只输出 7 行，一行一段，格式 `序号 段名｜一句话要点｜预计时长`：

```text
1 教学目标｜能在图片提示下说出 4 个周末活动短语；能用 be going to 问答计划｜随堂
2 重难点｜重点 be going to 句型；难点 be 动词随主语变化｜随堂
3 教学准备｜短语卡 4 张、Let's learn 挂图、对话录音｜课前 10′
4 教学过程｜导入 5′→新授 15′→操练 12′→产出 5′→小结 3′｜40′
5 板书设计｜左栏短语、右栏问答句型、下方时间词｜随堂
6 作业布置｜基础：抄写短语；提升：写 3 句周末计划｜课后 15′
7 教学反思｜课后回答三问：目标达成证据 / 学生卡点 / 下次改什么｜课后 5′
```

- 第 4 行时长合计必须等于课时时长（小学 40′，初高中 45′，以学校实际为准）。
- 输出后停下，问一句：「大纲可以吗？要改哪一行？」

怎么算失败：多于或少于 7 行；第 4 行时长对不上；第一段就写出全文。

## 3 第二段：draft

按大纲逐行展开，段落与大纲一一对应，标题层级固定（课件生成会按标题取内容）：

```markdown
# <课题>

| 项 | 内容 |
|---|---|
| 学段 / 学科 | 小学 / 英语 |
| 教材 / 单元 | 人教PEP 六年级上 / Unit 3 My weekend plan |
| 课型 / 课时 | 新授 / 第 1 课时（共 6 课时） |
| 授课班级 | 六(2)班 |

## 一、教学目标
## 二、教学重点与难点
## 三、教学准备
## 四、教学过程

| 环节 | 教师活动 | 学生活动 | 时间 | 设计意图 |
|---|---|---|---|---|

## 五、板书设计
## 六、作业布置
## 七、教学反思（课后填写）

## 引用来源
- knowledge/教材/人教PEP六上-U3.md：Let's learn 词表与 Let's talk 对话
- knowledge/作业反馈/六2-U2.md：上次 be 动词错误多，放进难点
```

每段的判定标准：

| 段 | 合格 | 不合格 |
|---|---|---|
| 目标 | 可观察的行为动词（说出、写出、圈出、复述、用…完成…），带条件和程度：「能在图片提示下说出 4 个短语」 | 了解、理解、掌握、体会、培养兴趣——课堂上看不见、查不了 |
| 重难点 | 重点取自目标；难点写学生卡在哪、为什么卡（引用作业反馈） | 重点难点写成同一句话 |
| 准备 | 教具、页码、设备逐项列，教师与学生分开 | 「多媒体课件」一词带过 |
| 过程 | 每环节有可照读的指令、组织方式、预设困难；时间合计等于课时 | 「讲解本课内容」「学生练习」 |
| 板书 | 用代码块画出布局，写实际板书文字 | 只写「见课件」 |
| 作业 | 分层，写清题量与用时，每项对应一个目标 | 「完成练习册」不写哪页哪题 |
| 反思 | 只留三问，课后填写 | 预先写好「效果良好」 |

- 全中文；英文只出现在语料、词汇、例句里。
- 不编造教材页码和原文；材料里没有的内容标「教材外补充」。

## 4 落盘

1. 路径：`knowledge/教案/<学段>-<学科>-<单元>-<课型>.md`，去掉斜杠，例如 `knowledge/教案/小学-英语-Unit 3-新授.md`。
2. 只在 `draft` 段落盘；`outline` 不写文件。
3. 已有同名文件：先 `read`，在原文上改，保留教师手写段落，不整篇覆盖。
4. 用 `write` 工具写入，再 `read` 回读，确认 7 个二级标题和「引用来源」都在。
5. 回报：完整路径、三条目标摘要、读了哪些依据、哪些没读到；提示「可以让课件生成把这节课做成课件」。

## 5 常见追问

- 「太笼统」：把教师活动改写成可直接照读的指令句，补时间与检查方式。
- 「换课型」：只改课型相关环节与目标动词，其余保留。
- 「难一点 / 简单一点」：只调语料难度与任务开放度，不删目标维度。

## 6 怎么算失败

- 第一次调用就给了全文。
- 引用来源缺失，或列了没 `read` 过的文件。
- 目标里出现「了解 / 理解 / 掌握 / 培养」。
- 过程时间合计与课时不符。
