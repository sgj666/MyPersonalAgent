# 教案生成

把一个表单或一段口述需求，变成可执行的 Markdown 教案，落到 `knowledge/教案/`。

## 1 先收齐字段

必需字段（缺哪个问哪个，一次问完，不要逐条追问）：

| 字段 | 说明 | 示例 |
|---|---|---|
| 学段 | 小学 / 初中 / 高中 | 初中 |
| 学科 | 学科名 | 英语 |
| 教材 | 版本 + 册次 | 人教新版 七年级上 |
| 单元 | 单元号与主题 | Unit 3 My weekend plan |
| 课型 | 新授 / 听说 / 阅读 / 语法 / 写作 / 复习 / 讲评 | 听说 |
| 课时 | 本单元第几课时、共几课时 | 第 2 课时 / 共 5 课时 |
| 目标 | 教师给的目标，或空着由你按课标补 | 能描述周末计划 |

可选：班级、学情、重点难点、作业形式、板书要求。

## 2 参考已有知识

- 先看 `knowledge/index.md`；有对应教材或教师手册页面时，用 `read` 读取 `knowledge/教材/…`、`knowledge/教师手册/…`，让目标、词汇、语篇与教材一致。
- 知识库里没有的内容按学科常识补，并在教案末尾「参考来源」里写清「教材外补充」，不要伪装成教材原文。

## 3 教案结构

按下面顺序写，标题层级固定，便于后续课件生成复用：

```markdown
# <课题>

| 项 | 内容 |
|---|---|
| 学段 / 学科 | 初中 / 英语 |
| 教材 | 人教新版 七年级上 |
| 单元 / 课型 | Unit 3 My weekend plan / 听说 |
| 课时 | 第 2 课时（共 5 课时） |
| 授课班级 | … |

## 一、教材与学情分析

## 二、教学目标

- 知识与技能：
- 过程与方法：
- 情感态度与价值观：

## 三、教学重点与难点

- 重点：
- 难点：

## 四、教学准备

## 五、教学过程

| 环节 | 教师活动 | 学生活动 | 时间 |
|---|---|---|---|
| 导入 | | | 5′ |
| 新授 | | | 15′ |
| 操练 | | | 12′ |
| 小结 | | | 5′ |
| 作业 | | | 3′ |

各环节时间之和必须等于本课时时长（小初 40′/45′，高中 45′）。

## 六、板书设计

## 七、作业布置

## 八、教学反思（课后填写）

## 参考来源
```

要求：

- 目标是可观察的行为（「能说出 5 个周末活动短语」），不要写「培养兴趣」这类无法验证的句子。
- 每个环节写具体指令、活动组织和预设的学生困难，不写「讲解本课内容」这种空话。
- 全中文；英文只出现在语料、词汇、例句里。

## 4 落盘

1. 文件名：`<学段>-<学科>-<教材简称>-<单元>-<课型>-第N课时.md`，去掉空格与斜杠，例如
   `knowledge/教案/初中-英语-人教七上-U3-听说-第2课时.md`。
2. 用 `write` 工具写到 `knowledge/教案/<文件名>`；目录不存在时先 `mkdir -p knowledge/教案`。
3. 已有同名教案：先 `read`，再在原文基础上改，不要整篇覆盖掉教师手写的部分。
4. 写完后 `read` 回读确认文件存在，再向教师报告：
   - 完整路径 `knowledge/教案/<文件名>`
   - 课时与三个目标各一行摘要
   - 提示「可以让课件生成把这节课做成 .pptx」

## 5 常见追问

- 「太笼统」：把「教学过程」的教师活动改写成可直接照读的指令句，补时间与检查方式。
- 「换课型」：只改课型相关环节与目标动词，其余保留。
- 「再难一点 / 简单一点」：只调语料难度与任务开放度，不删目标维度。
